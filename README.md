# WorldLeader Research · 全球权力传承研究

> 横跨两千年、覆盖四十个政体的最高权力交接制度比较研究。
> 在线阅读：<https://iwantleave.github.io/worldleader/>

## 这是什么

对 **40 个政体** 的最高权力交接制度逐一拆解：从西汉（前 202 年）到当代，涵盖世袭与选举、血缘与神权、禅让与政变等多种权力合法性类型。每篇采用统一的四维评估框架，逐位统治者评分，因此 40 篇可直接横向比较。

| 类别 | 篇数 | 覆盖 |
|------|:----:|------|
| 中国帝制 | 6 | 汉、唐、宋、元、明、清 |
| 东亚 | 4 | 日本天皇、日本首相、朝鲜王朝、越南诸朝 |
| 欧洲 | 12 | 拜占庭、英、法、德、俄、意、西、葡、荷、古希腊、罗马、波兰立陶宛 |
| 伊斯兰与内陆亚洲 | 4 | 哈里发帝国、奥斯曼、莫卧儿、蒙古及四大汗国 |
| 宗教传承 | 2 | 天主教教皇、达赖喇嘛与班禅喇嘛 |
| 现当代国家 | 11 | 美、苏俄、印度、韩、新加坡、土耳其、以色列、伊朗、墨西哥、巴西、阿根廷 |
| 综合比较 | 1 | 古今中外权力传承制度比较研究 |

合计约 **39 万字** 正文、**6600+ 行**结构化评估表格。

## 评估框架

| 维度 | 说明 |
|------|------|
| 继承是否顺利 | 合法性、程序正当性、过渡是否平稳 |
| 立太子是否成功 | 是否提前指定并稳定继承人（现代政体作相应适配） |
| 传位有无不良事件 | 政变、兵变、杀戮、废黜、权臣篡位、激烈内斗 |
| 传位是否正常 | 综合判定，✅ 正常 / ⚠️ 基本正常或有隐患 / ❌ 不正常 / — 不适用 |

## 站点说明

- 站点由 **GitHub Pages + Jekyll** 自动构建，**无本地构建步骤**：推送 Markdown 即自动发布。
- 40 篇研究源文件保持纯 Markdown，无需 front matter（GitHub Pages 默认启用 `jekyll-optional-front-matter` 与 `jekyll-titles-from-headings`）。
- 入口页 `index.md` 为研究总目，按 7 大类别组织。
- 站点框架（导航 / 版式）在 `_layouts/default.html`，正文样式由 `_config.yml` 中的 `theme` 提供。
